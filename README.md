# mockTest - Full-Stack Web Application

A full-stack web application designed for online test management and execution. Built with a modern **React** front end and a robust **Spring Boot** Java back end.

---

## 🛠 Tech Stack

### Front End
* **Framework / Library:** React (Vite / JavaScript)
* **Styling:** CSS3
* **Build Tool:** Vite

### Back End
* **Framework:** Spring Boot (Java)
* **IDE:** Spring Tool Suite (STS) / Eclipse
* **Build Tool:** Maven
* **Database:** MySQL / PostgreSQL (Configure in application.properties)
